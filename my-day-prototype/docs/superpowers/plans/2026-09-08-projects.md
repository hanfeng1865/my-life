# 我的项目 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a project workspace whose task completion automatically determines project progress and synchronizes with daily tasks.

**Architecture:** Keep projects in the existing persisted local data envelope. Put deterministic progress and synchronization operations in `src/local-data.js`, then have `App.jsx` own the two state collections and call those operations from either surface. Render the new UI in a focused `Projects` component and style it in `src/projects.css`.

**Tech Stack:** React 19, Vite, Node test runner, Phosphor icons, localStorage/Electron persistence.

## Global Constraints

- Progress is derived from complete project tasks; no editable project percentage exists.
- A daily copy has `projectId` and `projectTaskId`, and a project task may be included once per calendar day.
- Completion changes propagate in both directions.
- Match the supplied soft-blue, personal visual direction and keep the workspace responsive.
